# CartifyJS

CartifyJS is a modern and responsive shopping cart web application built with **HTML**, **Tailwind CSS**, and **JavaScript**.
The project focuses on clean UI design, smooth user interactions, product filtering, live search, and a dynamic shopping cart experience.

## 🚀 Live Demo

https://nourzzoubi.github.io/CartifyJS/

## 📌 Features

* Modern dark UI with yellow accent theme
* Responsive product grid layout
* Product cards generated dynamically using JavaScript
* Category filtering
* Live product search
* Shopping cart sidebar
* Add products to cart
* Increase and decrease item quantity
* Remove items from cart
* Cart item counter
* Subtotal and total price calculation
* Empty cart state
* No products found state
* Smooth hover effects and transitions

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* JavaScript
* Google Material Symbols

## 🛒 Cart Functionality

The cart system allows users to:

* Add products to the cart
* Increase product quantity
* Decrease product quantity
* Remove products from the cart
* See the updated cart count
* View subtotal and total prices

## 🔍 Search and Filter

Users can search for products by name, description, or category.
The filter buttons allow users to browse products by category such as:

* All
* Electronics
* Fashion
* Home
* Sports
* Audio

Search and filter work together for a smoother shopping experience.

## 📱 Responsive Design

The layout is responsive and works across different screen sizes.
Product cards display in a grid on larger screens and stack nicely on smaller screens.
